# Contributing to AGI Vault

We welcome contributions. This file explains how to propose changes.

How to contribute
1. Fork the repository and create a branch: git checkout -b feat/your-feature
2. Run tests and linters locally (add commands below if you have them).
3. Open a PR against main with a clear title and description.

Required checks
- Linting and unit tests must pass.
- PRs that introduce integrations or token handling must include a security checklist and a plan for secret management.

Coding conventions
- Keep components modular and documented.
- Add/update tests for any new behavior.

Issue & PR templates
- Use .github/ISSUE_TEMPLATE and .github/PULL_REQUEST_TEMPLATE to capture necessary info: summary, steps to reproduce, security impact, and checklist.
