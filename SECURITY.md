# Security policy

Contact
- If you discover a security vulnerability, please email absolute360global@gmail.com or open a private security issue.

Guidelines
- Do not include secrets in issues or public PRs.
- Provide a clear proof-of-concept and steps to reproduce.
- Allow maintainers reasonable time to respond and remediate before public disclosure.

Recommended practices
- Use a secrets manager for tokens and credentials.
- Enable secret scanning and dependency scanning in CI.
- Maintain logs and rotation policies for tokens.
